# বাজার দর (BazarDor)

**বাজার দর (BazarDor)** একটি বাংলা ভাষার দৈনিক বাজারদর ওয়েবসাইট, যেখানে নিত্যপ্রয়োজনীয় পণ্যের প্রতিদিনের বাজারমূল্য এক নজরে দেখা যায়।

## বর্তমানে কনফিগার করা প্রযুক্তিসমূহ (Configured Technologies)

- **Next.js 16 (App Router)** — পেজ রাউটিং এবং রেন্ডারিং
- **TypeScript (Strict Mode)** — টাইপ-সেফ কোডবেস
- **Tailwind CSS v4** — রেসপনসিভ স্টাইলিং এবং লেআউট
- **HeroUI v3 (`@heroui/react`, `@heroui/styles`)** — ইউআই কম্পোনেন্ট লাইব্রেরি
- **Gravity UI Icons (`@gravity-ui/icons`)** — আইকন লাইব্রেরি
- **ESLint** — কোড লিন্টিং

## ইনস্টলেশন নির্দেশিকা (Installation Instructions)

১. রিপোজিটরি ক্লোন করুন অথবা প্রজেক্ট ফোল্ডারে যান:

```bash
cd A07
```

২. প্রয়োজনীয় প্যাকেজসমূহ ইনস্টল করুন:

```bash
npm install
```

## ডেভেলপমেন্ট সার্ভার চালানোর কমান্ড (Development Server)

লোকাল ডেভেলপমেন্ট সার্ভার চালু করতে নিচের কমান্ডটি রান করুন:

```bash
npm run dev
```

এরপর ব্রাউজারে `http://localhost:3000` ঠিকানায় প্রজেক্টটি দেখুন।
